Python project of ETL Process with Oracle Databases. Process between transactional database amd data warehouse

We have class to any transformations, connecting to Oracle both by 'oracledb' module and 'sqlalchemy' to load data. We have also api key to google maps, 
because we need to get more information about place of customer location.

In this project 'configparser' modeule is used to extract parameteres from .ini file to build specific to Oracle connection strings
one of them is for oracledb, the second - for sqlalchemy.

Python 3.11.7

Library to download: pandas, sqlalchemy, oracledb, googlemaps
